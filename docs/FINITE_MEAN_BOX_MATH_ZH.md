# D1–D8 / E1–E5 的有限均值界：共同数学合同

本文件规定 D1–D8 × E1–E5 共40个组合的有限均值盒合同。单政策均值和两政策差值已接共同业务及网页入口，复用原读取、审核和证书重放。数值 D2/E1 和 D2/E4 仍使用各自证书协议，其他组合使用 finite 协议；符号信息使用单独的 symbolic 证书版本。专门历史会话适配器不接受新的符号信息类型。实际覆盖以能力登记与下述范围为准，组合被支持不代表任意参数都可识别。

## 信息、假设与目标

固定处理前简单无向网络、单位名单及背景。处理为二元向量。已知原随机分配律为 \(q(z)\)，允许某些安排概率为零。另行审核一致性、完整向量随机化、有限均值，以及**所有完整安排**上的均值充分性：

\[
E[Y_i(z)\mid W=w]=h_{i,z_i,e_i(z)}.
\]

暴露映射的定义不能推出这条科学假设。D6 还需明确：给定最终完整处理名单，第一阶段抽中的名额方案没有额外直接作用。分组抽签的分组也不意味着组间没有干扰。

唯一可用的总体信息是列明的精确条件均值
\[
b_{i,a,e}=E[Y_i^{obs}\mid T_i=a,e_i(T)=e,W=w],\qquad
\pi_{i,a,e}=\sum_zq(z)1\{z_i=a,e_i(z)=e\}>0.
\]
由随机化、一致性和均值充分性，得到 \(b_{i,a,e}=h_{i,a,e}\)。有限样本均值不能替代这个等式。全部已声明总体信息都必须保留并检查，不能只看目标用到的部分。

完整模型只含这些坐标等式和每个单位在所有安排下的均值界 \([l_i,u_i]\)。不含额外等式、均值顺序、联合分布、单调性或跨单位限制。其他模型必须交给相应求解器，不能忽略其约束。

单政策目标为 \(V(z^A)=\sum_iw_ih_{i,z_i^A,e_i(z^A)}\)。差值为 \(V(z^A)-V(z^B)\)，两端共用背景、评价范围、权重及完整模型；先合并相同坐标的正负系数，再求界。

## 分配律与暴露各自负责什么

| 设计 | 完整安排的概率 |
|---|---|
| D1 独立伯努利 | 各单位实际取值概率的乘积；允许异质概率及 0/1 边界 |
| D2 总体固定名额 | 满足总名额时为组合数的倒数，否则为零 |
| D3 两组固定名额 | 各组满足名额时，为各组组合数倒数的乘积 |
| D4 簇伯努利 | 同簇单位状态必须相同；再乘各簇一次抽签的概率 |
| D5 多组固定名额 | 与 D3 相同的组内均匀、组间独立公式，适用三组及以上 |
| D6 两阶段名额混合 | 对各第一阶段方案，乘其概率和该方案内的组内抽签概率，再求和 |
| D7 不等概率固定名额 | 明确列出的名单概率，或在所有满足名额的名单上归一化单位权重乘积；两种输入不能混用 |
| D8 重随机化平衡 | D7 基础分配律限制在满足处理前协变量平衡规则的名单上，再归一化；接受概率必须大于零 |

所有分组、概率和名额均来自绑定的设计对象，不允许调用者另传一个标签覆盖它。独立重放重新枚举完整分配，核对总概率为 1。

| 暴露 | 同伴状态 |
|---|---|
| E1 | 全部邻居中严格超过一半启用记 1，否则为 0；孤立节点为 0 |
| E2 | 邻居启用比例小于 1/3、介于 1/3（含）和 2/3、至少 2/3，分别为 0、1、2；孤立节点不在现有定义域 |
| E3 | 处理前明确列出的核心邻居中严格过半；每个单位必须有非空、属于其真实邻居的核心名单 |
| E4 | 启用邻居的准确人数；孤立节点为 0 |
| E5 | 是否至少有一位邻居启用；孤立节点为 0 |

可行坐标由全部二元安排产生，不能将零支持但可行的坐标删除，也不能为某节点创造其映射永远不会产生的状态。

## sharp 界与可达性

将目标写成 \(\theta=\sum_cd_ch_c\)。已知坐标取 \([\ell_c,u_c]=[b_c,b_c]\)，其余取审核后的节点均值界。则
\[
L=\sum_c\min(d_c\ell_c,d_cu_c),\qquad
U=\sum_c\max(d_c\ell_c,d_cu_c).
\]
每个坐标独立选择相应端点即可同时达到两界，并保持全部 A4 等式。连续结果用常数潜在结果实现；二元结果用独立于分配的均匀随机数阈值构造实现。两端均值表的凸组合仍满足全部条件，所以整个区间可达。证书既检查全模型界的有效性，也检查两个达到端点的完整均值世界。

二元结果的均值界先与 [0,1] 相交；若用户声明的是结果本身几乎处处的界，先求允许的二元结果集合再取凸包。空集合应报告不相容。

**软件沿用已有入口约定**：目标净系数非零、事件有正支持但未给对应均值时，要求补充信息，不自动报告 PARTIAL。若完整 A4 已固定所有目标坐标，得到 POINT；不能强行给一个非退化区间。未给值的抵消坐标不需要为该差值补数。

有限枚举目前限制 D1–D6 最多12个节点，D7/D8 最多8个节点。这是验证资源边界，不是数学命题只适用于小网络。COUNT 结果的整数实现、加权/分组暴露及一般联合约束不在本合同内。D2/E1 均值顺序仍走其专门合同。D7/D8 复用已有完整分配律，不改变数学 Core。

## 先给上下界公式，再代入数值

设 C 是全部可行的（对象、本身状态、同伴状态）坐标，K 是材料明确提供的总体均值坐标。以下公式对每个满足节点界限的参数向量 b 成立：

```math
L(b)=\sum_{c\in K}d_cb_c+\sum_{c\notin K}\min(d_cl_c,d_cu_c),
\qquad
U(b)=\sum_{c\in K}d_cb_c+\sum_{c\notin K}\max(d_cl_c,d_cu_c).
```

符号入口仍要求明确 K、每个坐标的含义、正支持、全部科学条件、数值型科学界限和模型完整性。它只是让已声明的总体均值保留为参数，不能把精确数值的漏填自动改成符号，也不能把有限样本升级为总体信息。符号与数值记录混填、符号均值顺序模型暂不支持。

对每个可行 b，已知坐标取 b，未知坐标按目标系数符号取相应端点，构造两个完整均值世界。它们满足全部已声明条件且达到 L(b)、U(b)，所以公式在声明的参数域内是 sharp。独立重放重新计算支持、参数域、目标系数和两个端点世界，未给值的 b 不会被替换为某个假定数值。宽度 U(b)-L(b) 在本盒模型中为常数；宽度为零即参数化 POINT，不要求先知道 b 的数值。

网页先显示公式和符号对应关系。已给精确总体数值时另列代入结果；仅给符号信息时不显示数值区间。辅助代入函数只做算术诊断，不批准新数值；正式数值结果需重新绑定材料和审核。一般 PARTIAL 可以有计算公式、优化问题或数值界，本实现仅覆盖这里的可分离均值盒模型。

## 文献与本项目推导的界限

[Aronow & Samii (2017), Annals of Applied Statistics](https://arxiv.org/abs/1305.6156) 将设计、暴露和目标分开讨论；[Manski (2013), The Econometrics Journal](https://doi.org/10.1111/j.1368-423X.2012.00368.x) 研究有社会互动时的识别与部分识别。它们提供研究背景，不能代替上面的具体模型证明。本项目的坐标盒子求界与二元实现是针对此完整均值合同的直接推导，不宣称是原论文的全部模型或原定理。

例程输出40组合各自的政策均值和两政策差值，共80条审核后的合成结果；部分组合有充分支持时自然退化为 POINT。符号测试另逐组合核对两类目标与数值路径一致。测试另检查支持内目标、非规则网络、缺项、拒绝、过期绑定和证书篡改。它们是明确给定的参考规格，不计作 LLM 读取准确率。

新增设计主要补完整联合分配律及其独立重放；新增暴露主要补状态映射及其独立重放，求界目标与审核流程复用。实现数量不必按 D×E 复制，但组合验收数量会随支持范围增长。若新暴露未定义某些节点、或新条件引入坐标间约束，就不能套用本盒模型。

生产端使用已有设计和暴露原语，重放端自行枚举完整二元安排、计算各设计的联合概率及暴露；二者只共享类型和输入声明检查。这是独立算法重放，不是形式证明系统认证。研究入口维持 synthetic 审核限制，production_admission 和 estimation_handoff_allowed 为 false；有限 PARTIAL 不直接进入估计或 Policy。
