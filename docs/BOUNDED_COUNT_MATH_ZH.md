本扩展沿用有限均值模型的证明方法，新增“邻居使用人数”坐标。它不是新的普遍识别定理，也不声称覆盖 D1–D6 与 E1–E5 的全部组合。

现有 POINT Core、D2/E1 求解器及验证器不变。D2/E4 的类型化输入、证明产生和独立重放在 cfm_id/bounded_count_contract.py、bounded_count_solver.py、bounded_count_verify.py。提交仍经过 bounded_policy.submit 或 bounded_contrast.submit 的原审核链。新证书不冒用旧 E1 的协议版本。

## 1. 模型和信息

固定处理前简单无向图 G、单位名单、结果定义、期间及背景 \(W=w\)。二元处理向量的原分配律是
\[
q(z)=\binom{n}{m}^{-1}{\bf1}\{\sum_i z_i=m\}.
\]
E4 定义 \(e_i(z)=\sum_{j\in N_i}z_j\)，签名 \(s_i(z)=(z_i,e_i(z))\)。孤立节点只有人数 0；人数 2 不能压成二元“高暴露”。

必须单独审核：

- 一致性：\(Y_i^{obs}=Y_i(T)\)。
- 完整向量随机化：\(T\perp\{Y_i(z):i,z\}\mid w\)，以及已知原分配律。
- 固定处理前网络、有限条件一阶矩。
- **所有二元安排**上的均值充分性：\(E[Y_i(z)\mid w]=h_{i,s_i(z)}\)，包括原试点没有支持的安排。这不是 E4 定义自动带来的结论。
- 每个节点在所有安排上的科学界限及完整模型声明。这里只允许分别的均值界和列明的精确均值，不允许漏掉其他等式、顺序、完整联合分布等限制。

给定清单 J 上的精确总体信息
\[
b_{i,a,e}=E[Y_i^{obs}\mid T_i=a,e_i(T)=e,w].
\]
这些条件事件须有正概率。在上述假设下，将事件内的完整安排按原条件概率平均，得到 \(b_{i,a,e}=h_{i,a,e}\)。有限样本平均数不能代替这个等式。

原支持概率可直接计数：
\[
\pi_{i,a,e}=
\frac{\binom{d_i}{e}\binom{n-1-d_i}{m-a-e}}{\binom{n}{m}},
\qquad d_i=|N_i|,
\]
不可行的组合数记 0。生产端复用现有精确支持引擎；独立验证端枚举原固定名额下的完整安排直接计数，不调用该引擎。

软件域为 \(1\le n\le12\)，\(0\le m\le n\)，二元或连续结果。12 是全安排独立重放的资源限制，不是数学命题的节点上限。所有实际可达签名都保留，包括不在评价名单中的单位。

## 2. 目标与界限

单个政策的目标为 \(V(z^A)=\sum_i w_i h_{i,s_i(z^A)}\)，其中 \(w_i\ge0,\sum_iw_i=1\)。
两政策目标为 \(\Delta=V(z^A)-V(z^B)\)，必须共用图、名单顺序、权重、结果、背景、A4 和 A5。

令 \(c=(i,a,e)\)。单政策系数为 \(d_c=w_i{\bf1}\{s_i(z^A)=(a,e)\}\)；
两政策系数为
\[
d_c=w_i\big({\bf1}\{s_i(z^A)=(a,e)\}-{\bf1}\{s_i(z^B)=(a,e)\}\big).
\]
先合并同一坐标，再求界。单政策均值不是“该政策减全不用”；两个政策的分别区间也不能直接相减当成 sharp 差值界。

已知坐标令 \([\ell_c,u_c]=[b_c,b_c]\)，未知坐标使用该节点审核后的均值界。给定完整模型下：
\[
L=\sum_c\min(d_c\ell_c,d_cu_c),\qquad
U=\sum_c\max(d_c\ell_c,d_cu_c).
\]
代码保留原入口约定：净系数非零的目标坐标若有正支持却未提供对应 A4，返回 NEEDS_INPUT；不把材料遗漏伪装成 PARTIAL。净系数为零的坐标不需为这个目标额外补数，但全部已声明 A4 仍须相容。

## 3. 为什么这些界是 sharp

有效性来自逐坐标的区间限制。下端点对正系数取下界、负系数取上界；上端点反向选择。零系数坐标可取中点，但每一个已声明 A4 坐标始终保持精确值。因此两个完整均值表分别达到 L、U。

连续结果可令 \(Y_i(z)=h_{i,s_i(z)}\) 为确定值，并使分配独立。二元结果使用独立于分配的均匀随机数，构造 \(Y_i(z)={\bf1}\{U_{i,s_i(z)}\le h_{i,s_i(z)}\}\)。它们同时满足本合同的均值充分性、随机化、A4 和界限。

若声明二元结果几乎处处有界，要先将允许结果集合限制到 \(\{0,1\}\cap[\ell_i,u_i]\)，再取其凸包作为均值范围。空集合不相容；“二元均值在 1/4 和 3/4 之间”不等于“二元结果几乎处处在两者之间”。

均值可行集合是盒子与坐标等式的交集，凸且紧。上下端点均值表的凸组合仍可行，并可用上述结果构造实现，所以每个介于 L 和 U 的值都可达。
这一证明只适用于声明的完整模型；加入跨坐标等式、均值顺序或联合分布限制后，不能继续套用逐坐标端点构造。

## 4. 保持同一个目标，放宽假设

四个小组两两合作，原试点四选二。每个正支持 E4 单元的精确均值均为 1/2。比较全使用减全不使用，四组等权；两端目标人数分别为 3 与 0，均不在历史支持内。

| 仅改变的科学条件 | 同一差值的识别集 |
|---|---|
| 所有安排的条件均值等于 1/2 | {0}，POINT |
| 放宽为条件均值在 [1/4,3/4] | [-1/2,1/2]，sharp PARTIAL |
| 只保留二元均值的 [0,1] 范围 | [-1,1]，sharp，但没有超出逻辑范围的信息 |

图、设计、目标、A4 和充分性不变；每层重新审核自己的界限。不能把最末一层说成无界或软件不支持。informative 比较的是本层 A4 前后的范围，不是跨层比较。
