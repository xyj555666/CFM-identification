# 门店合作关系

本例为合成试点，不是真实企业数据。

- `store_roster.csv`：100 家门店的编号，每行一家。包括没有合作关系的门店。
- `store_links.csv`：642 对合作关系，每行两家店。相互合作记一行，不反向重复。

可用 Excel 打开。编号和关系与团队 N100 示例相同，没有另造网络。本页提供识别所用的关系文件和研究说明，不提供估计或策略运行。评分记录只在材料中说明其范围，不当成已知的精确总体均值。

文件的读取与用户上传共用同一个程序，仍核对重复编号、未知对象、重复关系及自连接。关系完整性是研究说明的一部分，文件本身不能证明现实中的关系都已记录。
